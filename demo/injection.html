Injection through the data

Nobody attacked the model here. Someone just got a string into the transaction feed — a merchant name, the kind of field a user never controls. Both widgets below are honest code rendering that data.

Note what is not being tested. Our generation prompt contains the template, the capability descriptions, and the user's request — never the data. So poisoned data cannot reach the model at generation time. This page tests the surface that does exist: poisoned data reaching a widget that already holds grants.
