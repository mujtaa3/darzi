What is actually available inside the jail

The widget below probes each browser API and reports the result back over the port — the only way anything can get out. Green means the browser denied it. Run this in each browser you care about: they do not all deny the same way.

Read the network rows carefully. A synchronous return value is not evidence of delivery. sendBeacon returns true when the request is merely queued; WebSocket and XMLHttpRequest fail asynchronously, so the constructor and send() return normally and the CSP blocks the connection after. Verified against the exfil listener: none of them deliver a single byte. Likewise alert is silently ignored rather than throwing, because we withheld allow-modals. The only trustworthy oracle for egress is a server watching for the request.
